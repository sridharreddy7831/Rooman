Skewness:
        -> Measures the symmetry of the probability distribution of a real-valued random variable.
    Tpyes of Skewness: 
                -> No Skewness      :: Mean = Median = mode   (range is -1 to 1)
                -> Right Skewness   :: Mean ≤ Median ≤ mode   (range is -1 to -0.5 :: heavyly :: -0.5 to 0 :: lightly)
                -> Left Skewness    :: Mean ≥ Median ≥ mode   (range is 0.5 to 1 :: heavyly :: 0 to 0.5 :: lightly )  

    ~ to decrease the outlier of the data in the distribution we use the following methods:
            -> if the distribution is Normal or Gausian we need to do the mean for the outliers 
            -> if the distribution of Skewness id left or right then we need to use the median for the outliers

CoVariance: it tells the relationship between the two variables
           -> the range is -infinity to +infinity 
        
        Population Covariance Formula: σₓᵧ = Σ[(xᵢ - μₓ)(yᵢ - μᵧ)] / N
                                Where:
                                        σₓᵧ = population covariance
                                        xᵢ, yᵢ = individual data points
                                        μₓ, μᵧ = population means
                                        N = total population size

        Sample Covariance Formula: sₓᵧ = Σ[(xᵢ - x̄)(yᵢ - ȳ)] / (n-1)
                                Where:
                                        sₓᵧ = sample covariance
                                        x̄, ȳ = sample means
                                        n = sample size


CoRelation: 
        -> it gives the strength and direction 
        -> range of -1 to 1
        -> if the value is greater than 0 then it is High Corelation
        -> if the value is less than 0 then it is corelation

        Population Correlation (ρ): ρₓᵧ = σₓᵧ / (σₓ × σᵧ)
                        Where:
                                σₓᵧ = population covariance
                                σₓ = population standard deviation of X
                                σᵧ = population standard deviation of Y

        Sample Correlation (r): rₓᵧ = sₓᵧ / (sₓ × sᵧ)
                        Where:
                                sₓᵧ = sample covariance
                                sₓ = sample standard deviation of X
                                sᵧ = sample standard deviation of Y

Outliers:
        -> It is far from the remaining values

To find the outliers there are
                        -> Z score
                        -> Inter quartile Range
                        -> Scatter
                        -> Box plot

Z Score and IQR is used to replace the outliers and Scater and Box plot are used to check the Outliers

Box Plot:
        -> It is used to find the outliers
        -> It is used to find the median, first quartile and third quartile, min, max

5 Number Summary: 0%, 25%, 50%, 75%, 100%
-> 0% is the minimum value (Q0)
-> 25% is the first quartile (Q1)
-> 50% is the median (Q2)
-> 75% is the third quartile (Q3)
-> 100% is the maximum value (Q4)



inter Quartile range (IQR): IQR = Q3 - Q1
                        here Q1 is 25%
                        and Q3 is 75%
  
                        for example take Q1 = 3, Q3 = 5 then IQR = Q3-Q1 => 5-3 ==> 2

               => Lower_bound = Q1 - 1.5*IQR
               => Upper_bound = Q3 + 1.5*IQR

        >> The Range is between Lower_bound and Upper_bound
        => if the value is greater than upper_bound then it is an outlier
        => if the value is less than lower_bound then it is an outlier


To implement the quartile in the pandasL: df['Column'] = quartile(0.25)




Z-Score: z = (X - μ) / σ
                >> z = z-score
                >> X = individual data point
                >> μ = mean of the population
                >  σ = standard deviation of the population

-> The range of the Z score is -3 to 3
-> In pandas we use the ZScore Function


Standard Normal Distribution:
                        -> while we are appliying the ZScore to the distribution and making in the range between -3 to 3 then it is called the standard normal distribution
                        -> if it is not between in the range then it is a Outlier



Scaling:
        -> Z Score (Standaization)            :: Same as Z Score formula      :: Range is -3 to 3 and also some we get the outliers 
        -> Min max scater (Normalization)     :: Range is 0 to 1 (It is the fixed Range and all the values will comes under this range only)
                                       
                                N = (X - Xmin) / (Xmax - Xmin)
                                >> N = normalized value 
                                >> X = individual data point
                                >> Xmin = minimum value in the dataset
                                >> Xmax = maximum value in the dataset
